# Змейка

Минималистичная браузерная змейка. Работает без установки — просто откройте
ссылку.

**[Играть →](https://btur99.github.io/snake-game/)**

## Управление

- **Стрелки** или **WASD** — поворот.
- **Пробел** — начать, пауза, продолжить.
- **Enter** — начать заново после финала.
- **Свайп** по полю — поворот; на стартовом экране свайп запускает игру.
- **1–4** или плитки на старте — выбрать режим.
- Кнопка под полем — пауза; на паузе и после финала можно сменить режим.

## Режимы

| Режим         | Темп   | Особенности                   |
| ------------- | ------ | ----------------------------- |
| Медленный     | 160 мс | спокойная игра                |
| Средний       | 120 мс | режим по умолчанию            |
| Быстрый       | 90 мс  | для тех, кто уже освоился     |
| Ультрахардкор | 75 мс  | препятствия и красная палитра |

В ультрахардкоре на поле появляются препятствия. Столкновение с ними, как и со
стеной или собственным телом, заканчивает игру.

## Правила

- Поле 21 × 21. Змейка стартует длиной 3 клетки в центре.
- Светящаяся точка — еда: +1 к счёту и +1 сегмент.
- Развернуться на 180° за один шаг нельзя.
- Рекорд хранится отдельно для каждого режима и сохраняется в браузере.
- Если заполнить всё свободное поле — победа.
