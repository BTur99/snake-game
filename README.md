# Змейка

Минималистичная браузерная «Змейка» на HTML, CSS и Canvas. Без сборки,
зависимостей и внешних запросов: достаточно отдать каталог статикой.

## Запуск

```sh
python3 -m http.server 8080
```

Откройте <http://localhost:8080>.

## GitHub Pages

Деплой статики настроен через GitHub Actions
(`.github/workflows/pages.yml`): workflow собирает `_site` из `index.html`,
`index.css` и `index.js` и публикует его.

Один раз после создания репозитория:

1. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Сделайте push в `main` или запустите Actions → Deploy to GitHub Pages →
   Run workflow.

Сайт будет доступен по адресу `https://<owner>.github.io/<repo>/`. Если Pages
уже включены, источник можно переключить через CLI:

```sh
gh api --method POST repos/<owner>/<repo>/pages -f build_type=workflow
# если настройка уже существует:
gh api --method PATCH repos/<owner>/<repo>/pages -f build_type=workflow
```

## Управление

- **Стрелки** или **WASD** — поворот; на стартовом экране тоже запускают игру.
- **Пробел** — начать, пауза, продолжить.
- **Enter** — начать; после игры или победы — начать заново.
- **Свайп** по полю (мышью или пальцем) — поворот; на стартовом экране свайп
  запускает игру.
- **1–4** на стартовом экране — выбрать режим; клик или тап по кнопке режима
  тоже выбирает его. После выбора фокус переходит на «Начать», поэтому
  Пробел/Enter сразу запускают выбранный режим.
- Кнопка справа под полем — пауза и продолжение.
- **Сменить режим** на экранах паузы, проигрыша и победы — вернуться на
  стартовый экран с тем же режимом и свежим полем.

Игра автоматически ставится на паузу, если вкладка скрыта или окно потеряло
фокус.

## Режимы

| Режим         | Шаг    | Препятствия  | Тема    |
| ------------- | ------ | ------------ | ------- |
| Медленный     | 160 мс | нет          | обычная |
| Средний       | 120 мс | нет          | обычная |
| Быстрый       | 90 мс  | нет          | обычная |
| Ультрахардкор | 75 мс  | 6 блоков 2×2 | красная |

Средний выбран по умолчанию. Скорость задаёт интервал шага и не растёт во
время игры.

## Правила

- Поле 21 × 21, змейка стартует длиной 3 клетки в центре и смотрит вправо.
- Каждое съеденное яблоко даёт +1 к счёту и +1 сегмент.
- Стена, собственное тело и — в ультрахардкоре — препятствия означают конец
  игры. Разворот на 180° за один шаг невозможен.
- Препятствия не появляются в безопасной стартовой зоне и на змейке; еда не
  спавнится на препятствиях.
- Если заполнить всё поле (с учётом препятствий) — победа.
- В ультрахардкоре поле, интерфейс, змейка, еда и препятствия окрашены в
  спокойные красные оттенки. На стартовом экране препятствия не видны: они
  появляются после начала игры.
- Рекорд хранится в `localStorage` отдельно для каждого режима
  (`snake:record:v2:<режим>`) и переживает перезагрузку страницы. Старый рекорд
  `snake:record:v1` мягко переносится в средний режим.

## Структура

```text
index.html   разметка, canvas, оверлеи, HUD
index.css    тёмная тема, красная тема ультра, типографика, адаптив
index.js     конфигурация режимов, логика, ввод, рендер, игровой цикл
README.md    этот файл
```

Вся логика шага, коллизий, еды, счёта и генерации препятствий — чистые функции
без DOM в начале `index.js`. Игровой цикл построен на `requestAnimationFrame` с
фиксированным шагом и аккумулятором; шаг берётся из выбранного режима. Canvas
масштабируется под `devicePixelRatio`, цвета читаются из CSS-переменных при
смене темы.
